# About
This is a system that allows to quickly add player movement in the top-down game. Important thing about this is that it doesn't require much thought into implementing, just take the scripts and paste them into your project. Scripts are intentionally really simple to read and modify so if you need to add some feature or remove feel free to mess with the code. Project also comes with a demo scene that shows what these scripts have to offer. This repository will be the part of the bigger project which goal would be to allow quick implementation of the most common systems in the top-down style game.
# Contributing
You can fork this repository and make changes or create an issue that may or may not be fixed in the future but as for the creating commits it's a big no. This isn't meant to be a long lasting project.
# Updates
Updates for this will continue to a time when I think the system is good enough to not be changed. After that decisions is made there will be no further updates to this repository.
